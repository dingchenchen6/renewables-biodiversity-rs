一句话判断

可以做,而且时机好。但"光伏使绿度如何变化"已有全国 30 m 评估(Li 等 2024),本工作流的新意不在绿度本身,而在四点:未建站点反事实与预趋势检验、绿度与异质性并列、风电同框、物种暴露并对照 NEE 情景。

2017Q4 – 2024Q2

Global Renewables Watch 为全球每个光伏电站和陆上风机标注了季度精度的建设日期。

这让"建设前后、早建与晚建"的交错双重差分第一次可以在全国尺度上做。

1
暴露:真实设施足迹与建设日期,而非县级政策指数
2
结局:栖息地状况的遥感指标与物种暴露,不依赖观测努力
3
反事实:晚建站点与匹配的未建点,按资源潜力匹配
4
检验对象:NEE 论文"全国集中"与"省级分散"两种情景的预测

定位:两篇论文各缺什么

Science 有事后视角但暴露与结局都测错了;NEE 有正确尺度但只是潜在冲突。

证据台账

区分有来源支撑、推断与待核实三类,只在第一类上立论。

有来源支撑

  • NEE:全国集中选址与丰富度优先区冲突低 4–7%,平均重叠物种少 11–33%;但与功能多样性和开阔/干旱生物群区冲突更大;分散选址更多重叠小分布区森林物种 [1]
  • GRW:光伏多边形与风机点位,季度建设日期,PlanetScope 4.7 米 [3]
  • 光伏遥感研究普遍报告"变绿",但空间异质且受气候混杂 [6, 7]
  • 青海荒漠野外:板下生物量增加,物种丰富度与香农指数显著下降 [8]
  • 内蒙古风电场:夜间增温、生产力下降 [9]
  • 全国 30 m:建设期绿度下降,森林最大、裸地最小;中小站点更强;运行期回升,约 21% 超过建设前 [16]
  • 57 站:湿润区耕地负响应最强,裸地 FVC、NPP 小幅上升且土壤水分增加;夜间增温为主 [17]

推断

  • 大型基地向荒漠、戈壁集中,而那里恰是公民科学数据最稀疏、NEE 预测功能多样性冲突最大的地方
  • "劣质绿化"若存在,应表现为绿度上升、异质性下降;站点尺度可检验,县级 MODIS 不可检验
  • [16][17] 的方向差异提示效应由原生境与干旱度共同调节:旱区以土壤水分增益为主,湿润区以遮光为主。两种机制可用土壤水分与板间/板下对比区分
  • 中小站点负效应更强,可能是选址的混杂(建在高绿度处),而非规模本身;需在匹配中控制建设前绿度

待核实

  • GRW 在中国的要素数量与建设日期准确度
  • 是否已有用建设日期构建反事实的全国风电研究(本次检索未见,不等于不存在)
  • [16] 的"建设期""运行期"如何界定,是否有任何对照组(需读全文)
  • 征求意见稿 [19] 的发布机构、日期与正式版
  • China BON-Birds 的获取途径
  • NEE 情景空间图层能否获取

核心问题与三个竞争假说

2017–2024 年中国新建的地面光伏与陆上风电,占用了哪些生境与物种栖息地;建设是否因果性地降低了站点及外围的栖息地状况;代价格局更接近 NEE 的"全国集中"还是"省级分散"情景?

H1 生境置换

建设转换自然生境,站点及外围状况下降,效应随距离衰减。

H2 中性或改善

站点多在退化地、裸地或农田,遮荫增湿带来变绿而无生境损失。已有证据:裸地站点运行期绿度回升、土壤水分增加 [16, 17]。

H3 同质化

绿度上升但结构与光谱异质性下降,生境质量损失被 NDVI 掩盖。

关键判别:同时看绿度与异质性

绿度上升不等于多样性上升,这是整条工作流最核心的洞见。

预测(自然生境站点,建设后)绿度 NDVI / GPP异质性 Rao's Q / 纹理夜间地表温度
H1 生境置换↓↓↑
H2 中性或改善0 或 ↑00
H3 同质化↑↓±

地面证据

青海荒漠野外调查:板下生物量增加,但物种丰富度与香农指数显著下降。遥感只看绿度会把 H3 误判为 H2。

证伪条件

H2 在裸地上已有支持,所以关键检验在两处:裸地站点的变绿是否伴随异质性下降(H3 对 H2),森林与湿润区耕地站点的下降是否在未建对照下仍然成立(H1)。具体而言,预趋势平坦、功效充足,而自然生境站点各项状况指标的建设后效应都与零无差异,则 H1 被否定;绿度上升处异质性并未下降,则 H3 被否定。

挑战的默认假设:① 遥感变绿即生态改善;② 荒漠是低代价选址;③ 政策强度可以代表生态暴露。

模块细节

M0 准备与数据治理

  • GEE 非商业项目已注册(renewable-conservation);国内网络需让脚本经代理访问 googleapis
  • China BON-Birds、保护地边界、生态保护红线需合作或授权;记录级观鸟数据不再分发
  • 联系 NEE 作者组索取情景图层
  • 看结果前预注册主结局、对照规则、距离环与功效门槛

M1 设施清单与建设日期

  • 主数据:GRW,筛选 COUNTRY = 'China',保留 construction_year 与 construction_quarter;2017 年一律为第 4 季度,是影像起点前已存在站点的左删失,不能当作建设时间
  • 补 2018 年前:中国 2015/2020 矢量光伏数据集的建设年份字段;农光互补 2010–2022
  • 容量与状态:Global Energy Monitor 追踪库;"已宣布未建"站点是天然反事实候选
  • 交叉验证:光伏用 TZ-SAM 的建设时间上下界校验 GRW 季度日期;风电用 GonshoreWT2024 与中国 2023 年风机图校验点位与覆盖
  • 随机抽 100–200 站在 Sentinel-2 时序上目视判读建设季度

M2 生境转换与物种暴露

  • 以建设前一年年度土地覆盖为基线:CLCD v1.0.5(1985–2025,中国专题)作主数据,GLC_FCS30D(GEE 内,止于 2022)作交叉核对 [20]
  • 按生境类型、生物气候区、海拔带统计占用面积
  • IUCN/BirdLife 范围 × 生境偏好 × 海拔构建 Area of Habitat;受威胁物种用 SDM
  • 用 NEE 的同一组指标计算真实选址冲突,判断更接近哪个情景
  • WDPA 对中国保护地覆盖不全,结论需注明

M3 栖息地状况的因果效应

  • 结局:NDVI、EVI、GPP;Rao's Q、GLCM 纹理;昼夜地表温度、蒸散、土壤水分;景观破碎度
  • Callaway–Sant'Anna 与 Sun–Abraham 互证;晚建站点作对照;CEM 匹配从未建设的点
  • 匹配变量:光伏潜力或风速(选址按它挑)、坡度、海拔、距道路/电网/居民点、建设前土地覆盖与绿度趋势
  • 稳健性:事件研究预趋势;HonestDiD;ERA5-Land 气候协变量;站点聚类或 Conley 标准误;按生境、干旱度、设施类型分层
  • 预设调节变量(来自 [16, 17]):建设前土地覆盖、干旱指数、站点面积等级;面积效应需在控制建设前绿度后再解释

M4 机制:变绿还是同质化

  • 同一批站点并列估计绿度与异质性的事件研究,直接检验 H3
  • 光学遥感看不到不透明面板下的植被:板间与外围用遥感,板下用野外样方补充,并在文中正面写明
  • 区分两条通路 [17]:旱区"遮荫增湿"(土壤水分 ↑、绿度 ↑)与湿润区"遮光限制"(土壤水分不变、绿度 ↓);用 ERA5-Land 或 SMAP 土壤水分与夜间地表温度共同判别

M5 生物学响应

  • China BON-Birds 样线邻近设施时做 BACI 比较
  • 公民科学:只用完整清单,保留时长、距离、人数;合并同日同点多人清单以去伪重复;"计数全为 1"清单剔除或单独建模
  • 多物种占域模型估计"距离 × 建设后"交互,不做县级聚合;先做功效分析

M6 综合

主图展示真实选址冲突落在 NEE 两个情景之间的哪个位置;荒漠专题检验扩张最快处是否也是数据最空处;政策含义是选址规则需同时约束丰富度与功能多样性、森林与干旱生物群区。

④ G1 建设日期校验(自动断点,100 站)

2020–2023 年每年随机抽 25 站(面积 ≥ 1 公顷)。取 GRW 季度前 8 个、后 6 个季度的哨兵-2 季度中位数反射率,用"季节哑变量 + 单一阶跃"模型找断点。

0 与 −1

77%

96%
阶跃信号较强的一半站点(R² 增益 ≥ 0.55)落在 ±2 内

按预设对策处理:事件研究把 GRW 季度前 2 个季度到当季设为过渡期,不计入前或后;主分析只用阶跃信号清晰的站点,其余站点改用年度时间窗作稳健性检验。方法上有两点教训:单纯的前后均值差会把季节转换误判为断点(第一版因此失效);窗口过窄会让断点堆在边界。本结果是自动判读,目视复核尚未做。

GEE 起步脚本(M1 pilot)

在 Earth Engine Code Editor 中运行。字段名已在项目 renewable-conservation 中实测核对。

// 已在 GEE 项目中实测:字段名以此为准(与目录页说明不同)
// Field names verified live; they differ from the catalog page.

// 读取并筛选中国 / load layers and keep China
var solar = ee.FeatureCollection('projects/sat-io/open-datasets/GRW/SOLAR_V1')
  .filter(ee.Filter.eq('COUNTRY', 'China'));
var wind = ee.FeatureCollection('projects/sat-io/open-datasets/GRW/WIND_V1')
  .filter(ee.Filter.eq('COUNTRY', 'China'));

// 2017 年均为第 4 季度:影像起点前已存在,属左删失,不作为建设时间
// 2017 = 2017Q4 only: left-censored sites present before the first image
var solarNew = solar.filter(ee.Filter.gte('construction_year', 2018));
var windNew  = wind.filter(ee.Filter.gte('construction_year', 2018));

print('China solar polygons / 中国光伏地块:', solar.size());
print('China wind turbines / 中国风机:', wind.size());

// 按建设年份统计 / counts by construction year
print('Solar by year / 光伏按年:', solar.aggregate_histogram('construction_year'));
print('Wind by year / 风机按年:', wind.aggregate_histogram('construction_year'));

// 2018 年后新建光伏的面积,按 2018 年土地覆盖(ESA CCI 代码)汇总
// area of post-2018 solar by 2018 land cover (ESA CCI codes)
print('Solar area by land cover / 光伏面积按土地覆盖:', solarNew.reduceColumns({
  reducer: ee.Reducer.sum().group({groupField: 1, groupName: 'landcover_in_2018'}),
  selectors: ['area', 'landcover_in_2018']
}));

// 导出供 R 做空间分析 / export for spatial analysis in R
Export.table.toDrive({collection: solar, description: 'GRW_solar_China', fileFormat: 'GeoJSON'});
Export.table.toDrive({collection: wind, description: 'GRW_wind_China', fileFormat: 'GeoJSON'});

R 端分析建议:did、fixest(sunab)、HonestDiD、MatchIt、exactextractr、terra、sf、landscapemetrics、spOccupancy。

主要风险与对策

风险对策
新颖性:全国绿度评估已有 [16]主张落在因果设计、异质性、风电与物种暴露;绿度结果作为与 [16] 的对照与复现,不作为卖点
遥感结局被当成多样性构念限定为栖息地状况与暴露;M5 做生物学验证
选址非随机晚建站点作对照;按资源潜力与可达性匹配;预趋势检验
GRW 日期是检出时间,不等于并网时间目视验证;与 GEM 投运年份比对;时间窗稳健性
板下植被不可见板间与外围用遥感,板下用野外数据;正面写入局限
风电的主要影响(撞击、回避)不在地表遥感只回答足迹与地表效应;撞击风险以迁徙通道叠加作扩展
公民科学的努力混杂完整清单、显式努力、去伪重复、占域模型、功效分析
